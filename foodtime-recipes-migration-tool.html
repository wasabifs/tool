foodtime recipes 搬遷小工具

只做一件事:把舊專案 recipes 集合的文件,搬到新專案,途中把 images 陣列裡的 base64 圖片改存到 Firebase Storage(順便壓縮),欄位換成網址。全程在你的瀏覽器裡執行,不會把資料傳到別的地方。

用之前確認一下:新專案的 Firestore 規則要先暫時放寬(搬完之後記得換回嚴格版本): 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
Storage 的規則也要暫時允許已登入使用者寫入。另外這個頁面要放到 https:// 網址下開啟（例如 GitHub Pages）,不能用 file:// 直接雙擊打開,不然 Google 登入會失敗。
